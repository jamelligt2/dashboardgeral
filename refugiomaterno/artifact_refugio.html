Regras de decisão — gatilhos práticos para agir (referência)
⛔ Pausar / Cortar
  • CPL > R$ 40 por 5–7 dias seguidos com verba já gasta
  • CTR < 1% + 0 leads após ~R$ 50 investidos
  • Página consome verba e não converte
✎ Ajustar anúncio / página
  • CTR < 2% → problema de criativo/oferta
  • CTR bom mas CVR < 5% → problema de página
  • CPL entre a meta e 1,6× a meta → testar variação antes de cortar
▲ Escalar
  • CPL ≤ R$ 25,00 de forma estável → subir orçamento gradual
  • CVR > 15% + CPC baixo → sinal verde
  • Aumentar verba 20–30% a cada 3 dias
